# Evidence Report — ≠ME「愛くださいませ」

- 版: 1.0（Phase 7）
- 調査基準日: 2026-09-05
- 対象: 音源、歌詞、制作、歌唱、振付、MV、ライブ／別バージョン、流通、受容、グループ内比較
- 対応資料: `claim_evidence_table.md`、`references_source_inventory.md`

## 0. Executive Summary

「愛くださいませ」は、≠MEの12th両A面シングルの表題曲として2026年6月9日に先行配信、6月24日にCD発売された。作詞は指原莉乃、作曲は齋藤奏太、編曲はAPAZZI。公式は、固定センターの概念をなくした11名編成と、グループ史上最高難度のダンスを作品の要点に掲げる。MVでは鈴木瞳美、谷崎早耶、冨田菜々風、永田詩央里が4人の堕天使を演じ、7体の人形とドールハウスを通じて、1999年7月の日本に作られた幸福を再現する。[S01–S05, S11–S12]

本調査の中心的な分析は次の五点である。

1. **敬語と命令の二重性**: 表題の丁寧な依頼形は、歌詞が進むにつれて愛の提示、証明、相手自身の要求へ増幅する。礼儀正しい表面が、所有と強制を隠すのではなく際立たせる。[S22 / CE-020]
2. **中心を消して焦点を増やす**: 「センターなし」は無焦点ではない。場面ごとに焦点を移し、4人の堕天使と7人の人形へ役割を配ることで、執着の主体を11人へ分散する。[S05, S11–S12 / CE-023]
3. **同一矛盾の媒体横断**: 作曲段階の《幻想即興曲》オマージュ、APAZZIの編曲、生演奏、akaneの繊細さ／呪い、茅野しのぶの薔薇／狂気、荒船泰廣の箱庭世界は、「美しさと危険」をそれぞれ音、身体、衣装、映像へ翻訳する。[S14–S20]
4. **ヒットの二重構造**: 発売前のライブ／短尺拡散と、発売週の強いCDセールスが重なってBillboard JAPAN Hot 100初首位に到達した。一方、翌週以降の順位急落は、話題性と総合順位の持続を同一視できないことも示す。[S30–S35, S47–S48]
5. **未解決を残す必要**: 調性、確定BPM、コード進行、全歌割り、MV全カット、CDTV版の詳細は一次確認が不足する。これらは作品理解の空白であり、推測で埋めない。

総合すると、本曲は「愛してほしい」という感情を、優雅なお願いとしてではなく、終演できないショー、解約できない契約、壊れる箱庭へ変換する作品と読める。ただしこれは資料に支えられた批評的Interpretationであり、作詞者・制作者が公言した唯一の正解ではない。[CE-043]

## 1. 調査方法とエビデンス規則

### 1.1 レイヤー定義

- **Fact**: 公式発表、商品カタログ、チャート、制作者・演奏者の一次発信で直接確認できる事項。
- **Observation**: 歌詞、映像説明、公開データに実際に現れる要素。直接精査できない場合は資料経由と明記。
- **Analysis**: 複数のFact / Observationの関係を説明する推論。
- **Interpretation**: 作品の意味に関する批評的仮説。作者意図とは区別する。

### 1.2 情報源の優先順位

1. ≠ME公式、KING RECORDS、公式YouTube、公式配信カタログ、Billboard JAPAN、Oricon。
2. 作曲・編曲・演奏・映像・衣装・振付の担当者本人による発信。
3. 業界媒体による一次コメント転載・チャート分析。
4. 個人分析、自動テンポ／キー推定は補助資料に限定。

### 1.3 YouTube公開データの時点観測

本調査では、≠ME公式YouTube上で公開されていたメタデータ・再生数・いいね数・コメント数等をYouTube Data API等を通じて時点観測した。使用した観測時点は2026-08-11、08-22、09-05であり、内部の保存先や管理ファイルは出典とは扱わない。[YT01–YT04]

## 4. 音楽——優雅さを終演させない駆動力

### 4.1 Fact

- 齋藤奏太が作曲、APAZZIが編曲。[S05, S13, S14]
- APAZZIによれば、《幻想即興曲》へのオマージュはデモ段階ですでに含まれていた。[S15]
- 生ギター、ベース、ピアノ／鍵盤、ストリングスの奏者がクレジットされる。[S14, S16, S17]
- 齋藤奏太は本曲の旋律を難しいと評価している。[S37]
- 公式Shorts等の区間名から、イントロ、1・2サビ、Dメロ、間奏、落ちサビ、大サビ、アウトロが区別される。[YT04, S22]

### 4.2 Observation

約4分10秒の中に、後半のDメロ、器楽間奏、落ちサビ、大サビ、アウトロまでが置かれる。第三者解析はBPM 147／150と近接する一方、調性はDm／Cmと割れる。[S44, S45] テンポは「約147〜150の機械推定」としてのみ扱い、調性は確定しない。終盤半音上転調も第三者音域資料による補助情報であり、公式譜による確認はない。[S46]

### 4.3 Analysis

多段の後半構造は、同じサビを単純反復するより、要求の強度を一段ずつ上げる働きを持つ。クラシック参照がデモ段階にあった事実から、ピアノ的な運動は豪華な後付け装飾ではなく、曲の骨格に近い着想だったといえる。APAZZIの編曲と生演奏陣は、それを現代的なダンス・ポップの推進力へ接続した。

ここで重要なのは、「クラシック＝上品」「ビート＝激しい」と二分しないことだ。上品さが高速で反復されるからこそ、礼儀正しいお願いは落ち着かず、切迫へ変わる。作曲者が認める旋律難度と、公式が掲げるダンス難度は、歌い手に二重の負荷を与える。ただし、難しさの具体的要因は公表されておらず、高音・跳躍・息継ぎ等の単一要素へ還元できない。

### 4.4 Interpretation

この音楽は舞踏会を彩る背景ではなく、幕を閉じさせない装置として読める。美しい運動が続くほど、語り手は愛の証明を次の段階へ要求する。高揚は解決ではなく、さらに強い要求へ到達するための階段になる。

## 5. 歌詞——「くださいませ」が隠さないもの

### 5.1 Observation

許諾歌詞では、次の語彙群が反復・交差する。[S22]

| 系統 | 内容の要約 | 機能 |
|---|---|---|
| 不可逆な移動 | 馬車、解けない魔法、月の道、片道切符 | 恋を帰還困難な旅にする |
| 契約／拘束 | 手首、ダイヤ、誓い、秘密の部屋、鍵 | 感情を証明・所有・封印へ近づける |
| 傷／装飾 | 痣、棘、涙、赤いドレス、薔薇、宝石、ティアラ | 苦痛と美を同じ表面に置く |
| 舞台 | 幕、ショー、拍手、静寂、スポットライト | 私的恋愛を公開の演目にする |
| 時間 | 前世／昨日、夜／夜明け、永遠 | 日常時間を逸脱させる |
| 捕食／服従 | ファム・ファタール、猫、怯える犬 | 力関係を固定せず反転させる |

### 5.2 Analysis

表題は丁寧な依頼形である。しかし歌詞の中で求められるものは、曖昧な好意から即時の証明、誓い、相手自身へ拡大する。日本語の慇懃さと、愛を知り示すことを迫る英語リフレインが並ぶため、依頼の形式と命令の機能が衝突する。敬語は暴力性を消す幕ではない。むしろ薄い幕として、その輪郭を美しく見せる。

恋人は観客とも重なる。幕を開け、スポットライトを浴び、拍手で承認されるショーにおいて、相手は当事者であり目撃者である。静寂が対置されるため、相手には無反応でいる自由も少ない。語り手は愛を乞う演者でありながら、相手へ拍手と役割を要求する演出家にもなる。

傷と宝飾の連鎖も同じ反転を作る。痣、棘、涙は、ドレス、薔薇、宝石、ティアラの近くに置かれ、苦痛が身につけるもの、光るもの、贈るものへ加工される。美しさは傷の反対ではなく、傷を保存する形式になる。

### 5.3 Interpretation

本曲の語り手は、単純な被害者でも支配者でもない。愛に運ばれ、傷つきながら、その愛を失わないために相手を契約とショーへ組み込む。愛が本物だと証明させ続けなければ世界が崩れるため、お願いは終われない。この循環が「呪縛」の実質だと読める。

この解釈は、指原莉乃の明示的な歌詞解説ではない。本人が公表したMV打合せの別案は、完成版以外の人物関係が検討されたことを示すだけで、歌詞の唯一の答えを与えない。[S36]

## 6. 歌唱・振付——固定中心を捨て、視線を捕まえる

### 6.1 Fact

- 初披露とMVは菅波美玲を除く11名。[S11]
- 公式は「センターという概念」をなくし、≠ME史上最高難度のダンスへ挑戦したと説明する。[S05, S11]
- akaneは、花の繊細さ、呪いのように残る感情、細部、シンクロ、視線、静寂を重視したと語る。[S12]
- 公式はDance Practice、One-Take Dance、Dance version、Position Shuffle、メンバー別Shortsを公開した。[S06–S09, YT04]

### 6.2 Analysis

センターなしは「全員が同じ」「誰も目立たない」という意味ではない。4人の堕天使／7人の人形という配役がある以上、場面ごとの焦点は存在する。固定された一人に焦点を集めず、時間と隊形に沿って焦点を移動させる仕組みと考えるべきである。冨田菜々風が要所で視覚的中心になることと、公式のセンター職がないことは両立するため、二次資料の「冨田センター」表記を公式Factへ格上げしない。

最高難度も運動量だけを意味しない。akaneの説明に従えば、手先、視線、同期、静止まで揃える精度を含む。11人が同じ残像を作るほど、一人の執着は群像的な呪いへ変わる。固定主人公を追えば安全に物語を外から見られるが、視線の発信源が入れ替わると、観客は次々に別の顔から同じ要求を受ける。

衣装もこの身体設計に参加する。茅野しのぶが説明する「踊ると真紅の薔薇」「可憐さと狂気」は、akaneの「花／呪い」と対応する。[S20] 可憐さを捨てて強くなるのではなく、可憐な動きそのものが脅威になる。

### 6.3 Interpretation

本曲の群舞は、個人の感情を多数で飾るバックダンスではない。11人全員が同じ要求の別の顔となり、誰が語り手かを確定させない。センターを消した結果、中心が空になるのではなく、観客を捕らえる中心が増殖する。

## 7. MV——作った世界から見返される

### 7.1 Fact

MVの4人の堕天使は、恋によって翼を失った存在である。彼女たちは天界の暮らしを再現するためドールハウスと7体の人形を作り、人形劇の世界へ入る。そこは1999年7月の日本で、女子高生の日常と愛への思いが、作られた幸福の崩壊へ向かう。[S12]

公式記事は、高速カット、CGを用いたダンス、甘く危険な雰囲気を特徴として挙げる。[S12] 荒船泰廣が監督し、EPOCHの実績ページと本人発信で照合できる。[S18, S19] ドローン撮影はTERU FPV。[S21]

### 7.2 Observation

公開資料と公式Shortsから、4:3の古いビデオ風画角、1990年代末を示す携帯電話や服装、存在しない日付「1999年7月32日」が確認・報告される。[YT04, S40–S43, S50–S51] 本調査環境では全編をフレーム単位で再記録できていないため、各カットの秒単位分析は行わない。

### 7.3 Analysis

堕天使たちは失った天界へ帰還せず、模型と人形で再現する。この行為は原物／コピー、現実／舞台、創造者／被造物という二重性を作る。「7月32日」は具体的な1999年という記憶に、カレンダー上ありえない延長日を足す。幸福を一日だけでも終わらせたくない願いが、世界の偽物性を最も明確に示す印になる。

高速カット、CG、ドローンは壮観さを作るだけでなく、観客の視点を安定させない。箱庭を上から見る創造者の目と、内部で運ばれる人形の目が往復し、観客は「見る側」に留まれない。歌詞で恋人が観客と当事者を兼ねたのと同様、映像の観客も箱庭の外と内を行き来する。

### 7.4 Interpretation

MVは失恋の悲劇だけでなく、失った愛を作品として保存しようとする創作の悲劇を描く。4人は傷ついた堕天使であり、7人の世界を作る作者でもある。しかし被造物は完全には従わず、幸福は崩れる。愛を所有可能な模型へ変えた瞬間、模型の側から見返される。この反転が、歌詞の「お願いが命令になる」構造を視覚化する。

## 8. 通常版とTHE FIRST TAKE版——身体と声の二つの精度

### Fact

2026年7月31日、≠MEはTHE FIRST TAKE #691へ初登場し、APAZZIによる特別リアレンジで本曲を一発撮り披露した。通常版と同じGuitar、Bass、Piano、Strings奏者が参加した。冨田菜々風は歌が鍵になると考え、全員で何度も練習したと説明する。この版は9月2日に「愛くださいませ - From THE FIRST TAKE」として配信された。[S23–S29]

### Analysis

通常版では難しい旋律と最高難度の群舞が同時に課される。THE FIRST TAKE版はダンスを外すことで、呼吸、声の入り、音程、声色、重なりを前面化する。同じ曲に二種類の精度——位置と視線を揃える身体の精度、声を受け渡す音楽の精度——があることを示す比較資料になる。

同一編曲者・同一演奏陣の起用は、別曲化より原曲の潜在要素を拡大する条件を作る。ただし、本調査では両版の波形、キー、テンポ、楽器配置を厳密比較できていないため、具体的なミックス差は未確定とする。

### Interpretation

通常版では「お願い」が11人の身体を持ち、THE FIRST TAKE版では身体の装飾を減らして11人の声へ戻る。豪奢なショーと切実な懇願は別々の意味ではなく、二つの上演形式を往復して初めて同居する。

### 9.3 Analysis

Hot 100の94位は、CD発売前にも一定のストリーミング／動画／SNS接触が存在したことを示す。発売週には強いCDセールスが加わって総合首位へ跳ねた。翌週42位、次週74位への移行は、首位が発売週へ大きく集中したことを示す。他方、8月から9月にもMVが日平均約5.38万回増えているため、「順位が落ちた＝関心が消えた」ともいえない。

正確な結論は、二つの時間軸を分けることにある。チャート順位は発売週に鋭い頂点を作り、動画視聴はその後も緩やかに続いた。SNS話題、CD購入、動画視聴は重なるが、同一の現象ではない。

レーベルの「約5万件」と指原莉乃の「1万件超」は拡散の規模感を示すが、音源使用数、ハッシュタグ数、プラットフォーム横断数のいずれかは明示されない。同じ定義の成長曲線として計算しない。

## 10. ≠ME内の位置——過去の語彙を、中心のない人形劇へ

### Fact

比較対象の公式資料では、「チョコレートメランコリー」はダーク／狂気、「天使は何処へ」は天使と自己決定、「アンチコンフィチュール」は甘さへの反語、「モブノデレラ」は主人公になれないシンデレラ、「排他的ファイター」は直前作の強い対立表現を主軸に持つ。[C01–C05]

「チョコレートメランコリー」「アンチコンフィチュール」と本曲では、APAZZI、a.k.a. JAKE、三池智之が共通する。[C01, C03, S05]

### Analysis

本曲は過去作のモチーフを単純再演しない。

- ダークな恋愛は、チョコレートから敬語・薔薇・宝石へ表面を変える。
- 天使は、純粋さの記号から、翼を失い箱庭を作る創造者へ変わる。
- 「甘いだけではない」という反語は、甘さを残したまま内部へ傷と命令を入れる質感になる。
- シンデレラ的な主人公性は、固定センターを消し、4＋7の入れ子へ分散される。
- 直前作で一人へ収束した強度は、11人の同期と移動焦点へ配り直される。

### Interpretation

≠MEが継続してきた「かわいいものの内部にある痛み」を、本曲は中心のない群像へ更新した。過去作では主人公一人が背負った矛盾を、今回は11人、箱庭の二世界、そして拍手を求められる観客までへ分配する。この意味で「センターなし」はフォーメーション上の特色に留まらず、作品全体の語り方である。

ただし、共通モチーフやスタッフ名は直接的な続編・影響関係を証明しない。制作証言のない系譜はAnalysisとしてのみ扱う。

## 11. 統合Interpretation——愛の保存が愛を壊す

歌詞、音楽、身体、映像を一つの因果物語へ乱暴にまとめるべきではない。それでも、別々の一次資料が支える要素の間には、繰り返し同じねじれが現れる。

| 媒体 | 美しい／丁寧な表面 | 内側の圧力 |
|---|---|---|
| 言葉 | 敬語、花、宝石、舞台 | 命令、所有、傷、拍手の強制 |
| 音楽 | クラシック参照、ピアノ、弦 | 高速感、多段構造、難旋律 |
| 身体 | 花の繊細さ、真紅の薔薇 | 最高難度、同期、呪い、視線 |
| 映像 | 天使、ドールハウス、1999年の思い出 | 翼の喪失、作られた幸福、崩壊 |
| 公開 | 短尺の親しみやすい入口 | フル尺、群舞、歌唱版へ増殖する要求 |

語り手は愛を永遠にしたい。そこで契約し、飾り、舞台化し、模型化する。しかし保存の手続きが増えるほど、愛は自由な感情から役割へ変わる。相手は恋人であるだけでなく証人、観客、人形となり、語り手自身も終演できない演者になる。

「愛くださいませ」という一見つつましい言葉は、この全体を一点に圧縮する。お願いである限り、相手には断る余地があるはずだ。だが曲は、その余地を音楽の高揚、群舞の視線、舞台の拍手、箱庭の壁で少しずつ塞ぐ。愛を失わないための美しい装置が、愛を呪縛へ変える——これが本調査の統合的な読解である。

## 13. 結論

「愛くださいませ」の成果は、強い曲・難しいダンス・豪華なMVの足し算だけでは説明できない。作曲段階のクラシック参照、APAZZIと演奏者による音響、指原莉乃の敬語と傷の語彙、akaneの同期と静寂、茅野しのぶの真紅の薔薇、荒船泰廣の箱庭が、互いに同じ矛盾を別の感覚へ翻訳する。その矛盾とは、愛を美しく保存しようとする行為が、愛を所有と呪縛へ近づけることである。

そして固定センターの不在は、その矛盾を一人のキャラクターへ閉じ込めない。11人、4人と7人、演者と観客、作者と人形、通常版とTHE FIRST TAKE版の間を焦点が移る。観客は主人公を見守るのではなく、次々と別の場所から向けられる「愛の証明要求」に巻き込まれる。

チャート初首位はこの作品の到達点の一つだが、作品の価値そのものとは分けて読むべきである。発売週の強い物理セールス、発売前からの拡散、発売後の継続視聴は、それぞれ異なる時間軸で作品が届いた証拠である。数字を正確に分け、未解決を残してなお、本曲が≠MEの過去の語彙を最も統合的に、かつ中心のない形式へ更新した作品だという評価は十分に支持される。
